# Railway Business Analytics | Power BI Dashboard

A Power BI business analytics dashboard designed to analyze railway passenger activity, bookings, revenue, delays, train capacity, occupancy, and operational performance.

The project demonstrates data analysis, DAX calculations, interactive filtering, and business-focused dashboard design using Power BI.

---

## Dashboard Overview

The dashboard contains two analytical pages:

### 1. Passenger & Revenue Insights

Focuses on:

- Passenger and booking performance
- Revenue trends
- Revenue by route
- Revenue by travel class
- Payment method analysis
- Train-type performance
- Passenger and booking insights

### 2. Railway Operations & Performance

Focuses on:

- Train capacity
- Occupancy percentage
- Average journey distance
- Railway-zone delays
- Booking status by train type
- Monthly average delay trends
- Revenue by train type
- Operational performance

---

## Key KPIs

The dashboard includes key business and operational KPIs such as:

- **Average Occupancy:** 79.92%

- **Average Journey Distance:** 804 km

- **Average Delay**
- **Total Revenue**
